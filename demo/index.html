      How an investigation runs

      An L1 analyst's job on an alert is evidence gathering followed by a judgement and a written rationale. The agent does the gathering and drafts the judgement; deterministic code does the detection and screening; controls check the result; a person decides.

      AlertTransaction monitoring or sanctions screening hit, with the triggering transactions.
      Agent loopThe model chooses tools, reads results, and repeats until it can return a JSON decision.
      ToolsKYC profile, transactions, 12 typology detectors, sanctions screening, policy search.
      ControlsGrounding, sanctions hard stop, dual control against the rules engine, evidence checks.
      AnalystApproves or overrides with a reason. Every step is in the audit trail.

      Tools the agent can call

      get_alertRule, date, summary and triggering transaction IDs
      get_customer_profileKYC data, expected activity, PEP status, EDD date, known counterparties, expected events, documents
      get_transactionsFiltered activity up to the alert date with a summary
      detect_typologiesStructuring, mule pass-through, round-tripping, dormancy, account takeover, PEP funds, velocity, large inflows, higher-risk jurisdictions, unapproved beneficiaries, funnel accounts, income shifts
      screen_sanctionsFuzzy name match (Jaro-Winkler) plus DOB, nationality and country to grade hits STRONG, POSSIBLE or WEAK
      search_policyBM25 retrieval over the policy, returning citable POL- sections

      Every tool is scoped to the customer on the alert, so the model cannot read other customers' data.

      Controls before a human sees it

      CTRL-SCHEMAUnusable model output falls back to the offline investigator
      CTRL-GROUNDINGCited IDs must have come from a tool in this case; invented ones are removed and flagged
      CTRL-SANCTIONSA potential true sanctions match can never be closed by the agent
      CTRL-DUALIf the model and the independent rules engine disagree, a senior analyst reviews
      CTRL-EVIDENCEEscalations need evidence; closures need mitigation when the score is elevated
      CTRL-TIPOFFAn escalation that suggests contacting the customer is flagged for MLRO approval
      CTRL-HITLNothing is actioned automatically; overrides need a reason
